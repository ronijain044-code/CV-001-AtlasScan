# Security Policy

## Authorized Testing Only

AtlasScan is intended for authorized security assessment and defensive research.

Only use it against systems you own or where you have explicit permission to test.

Do not use AtlasScan to access, disrupt, or assess systems without authorization.

## Vulnerability Findings

AtlasScan reports potential vulnerabilities based on detected product and version information.

A version-range match is not proof of exploitability. Actual exposure can depend on configuration, installed modules, patches, backports and deployment context.

## Reporting a Security Issue

For security issues in AtlasScan itself, provide the affected version, component, reproducible steps, expected behavior, actual behavior and security impact.
